วิธีใช้งาน
1. คัดลอกไฟล์ AuDataPreload.exe ไปไว้ในโฟลเดอร์เกม Audition ที่มีไฟล์ Audition.exe 
2. เปิดโปรแกรม AuDataPreload.exe จากโฟลเดอร์ดังกล่าวก่อนเข้าเกม
3. รอให้โปรแกรมโหลดข้อมูลล่วงหน้าเสร็จ แล้วเปิดเกม Audition ตามปกติ
โปรแกรมนี้ช่วยโหลดข้อมูลเกมล่วงหน้า เพื่อลดอาการกระตุกที่เกิดจากการอ่านไฟล์ ผลลัพธ์ขึ้นอยู่กับสเปกเครื่องและหน่วยความจำที่มีอยู่

How to use:
Copy AuDataPreload.exe to your Audition game folder (the folder containing Audition.exe).
Run AuDataPreload.exe from that folder before starting the game.
Wait for preloading to finish, then launch Audition as usual.
This program preloads game resources to help reduce disk-related stuttering. Results may vary depending on your system.


CommandLine
-Path "FolderAudition" = Set path folder audition
-CC = Clear standby cache all process
-EW = Empty working set all process
